# APCSAFinalProjectKT
Final Project code repository for trivia game for AP CSA Final Project. 

For this project, I used the free Gemini API key plan, which only allows for 1-2 runs of this program. When starting the app, it will work the first 1-2 times, but, afterwards, it will show an error message due to the API token limits being met. 

Both the text-based version and UI-version in Java Swing of the Trivia app have been created.
